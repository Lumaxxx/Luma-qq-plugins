# 语言卫生：词句权重过高与复读塌缩的治理

大模型是自回归的：一个词出现得越多，后文生成它的概率越高；概率越高，它出现得越多。
最后会塌缩成只会输出那几个词（B 站 BV1yfw1z4EbX 里 Evil 的「好的 / 定位」就是这个）。

本方案不改模型权重（也改不了），而是在**四个位置**上打断这个正反馈：

```
上下文燃料 → 注意力分配 → 生成期概率 → 输出
```

## 一、输入节流（不花模型）

`lib/group.js`

| 规则 | 说明 |
| --- | --- |
| 刷屏节流 | 最近 3 条对方消息两两相似（相同/包含）≥2 对 → 不接话 |
| 纯应答跳过 | 对方只发「嗯/好/晚安/睡了」，且上一条自己也是短应答 → 跳过 |

## 二、概率自增强检测（核心）

`lib/word-authority.js`

```js
escalatingPhrases(recentOwn)   // 同一个词在最近 3 条回复里 1→2→5 递增
suspectPhrases(recentOwn, recentUser) // 跨回复出现≥2 次、且对方没提
```

- 递增趋势 → **直接掐**（不问模型）
- 静态高频 → 小模型判 `KEEP / CLIP`（带最近 8 条对话，`temperature=0, maxTokens=6`）

## 三、上下文降权（断燃料）

| 方法 | 作用 |
| --- | --- |
| `scrubText()` | 把她旧回复里含被删词的句子去掉，不再喂回模型 |
| `scrubUser()` | 群友消息里同一个词最多留 2 次，多出的整句丢弃 |
| `balanceHint()` | 提示词里列出其它还活着的话题，把注意力分出去 |

## 四、输出硬删除

`WordClipper.cut()`：含被删词的句子直接剪掉；句子还有内容就留剩下的；全剪光就不接话。

```
「嗯，睡觉吧。明天吃什么？」 → 「明天吃什么？」
「嗯，睡觉」               → 不接话
```

恢复条件（不是时间衰减）：

```
出现次数 ÷ 其它词最高次数 ≤ 1.3  → 恢复
最近完全不再出现                → 恢复
群友自己在聊这个词（≥2 次）      → 不压制
```

删除名单持久化到 `word-clips.json`。

## 五、输出侧通用判重

`lib/repeat-guard.js`

| 判据 | 条件 |
| --- | --- |
| 字面相似 | 归一化后 bigram-Jaccard / LCS ≥ 0.5 |
| 包含关系 | 短句被上句包含 |
| 应答同类 | 晚安/睡吧/嗯/拜拜 互相等价 |
| 话题执念 | 某词在最近 5 条出现 ≥2 次且对方没提 |
| 词句过载 | 同一片段连续 ≥3 次，或整句只有 ≤3 种二字片段 |

排除：人设词（本鱼/白饭/token/阿圆）、群友正在聊的话题。

## 六、语义自检

字面相似度 ≥ 0.22 的灰区，问一次小模型：A 和 B 是不是同一件事？只回 YES/NO。
YES → 不接话。实测准确率 6/7，平均 0.79 秒。

## 七、解码惩罚（可选）

自定义 provider 的请求体带：

```json
{"frequency_penalty": 0.5, "presence_penalty": 0.2}
```

仅在走自定义 OpenAI 兼容通道时生效；宿主内置 provider 不透传。

> 实测：单独用惩罚挡不住「被指令强迫重复」，只能当辅助。

## 参数一览

| 参数 | 位置 | 默认 |
| --- | --- | --- |
| 恢复阈值 | `BALANCED_RATIO` / LUMA「恢复阈值」 | 1.3 |
| 判重相似度 | `repeat-guard.isRepetition` | 0.5 |
| 过载阈值 | `degenerateLoop` | 连续 3 次 |
| 自检触发 | LUMA「自检触发相似度」 | 0.22 |
| 频率/存在惩罚 | LUMA | 0.5 / 0.2 |
| 取样窗口 | `group.js` | 最近 5~6 条 |

## 测试

| 测试 | 结果 |
| --- | --- |
| 真实历史回放（20:24–20:30 + 23:47–23:50） | 旧回复 22/53 判重（41.5%）→ 新防线发送集合 0/67 近似重复 |
| 七类高压场景 | 发送集合 0 对近似重复；对照组 5/5 放行 |
| 语义自检 | 6/7 准确 |

## 已知边界

- 无法直接控制 logits（宿主 llm 层不可改）
- 纯同义、零字面重合的复述依赖语义自检，非 100%
- 硬删可能把句子剪碎
- 全剪光时她会沉默（设计上比复读好）
