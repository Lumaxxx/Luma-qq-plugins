# QQ 群「大肥鱼」拟人社交能力 · 设计与路线

目标：让 QQ 群里的机器人具备好感度/关系、群黑话理解、人格演化、识图认梗，并以自然的方式聊天。

## 现状审计（qq-groupmate 0.2.0）

| 能力 | 模块 | 默认 | 说明 |
| --- | --- | --- | --- |
| 说话风格学习 | `learner.js` | 关 | 按群提炼语气画像 → `learned/<群号>.md`，只学「怎么说」不学「说什么」 |
| 群友档案 | `people.js` | 开 | 事实/事件、重要度衰减、跨群可见 |
| 分层记忆 | `memory.js` / `recall.js` | 开 | 按小时归档 + `[回忆:]` 检索 |
| 群知识库 | `knowledge.js` | 关 | 手写 Markdown，关键词命中注入 |
| 查梗 | `bili.js` | 随 web | B 站搜索，`[查梗:]` |
| 联网搜索 | `web-search.js` | 开 | Bing 抓取，免 key |
| 识图 | `vision.js` | 已开 | 图片转 data URL 交给视觉模型 |
| 表情包 | `stickers.js` | 已开 | 本地目录 + `[表情:名字]` |

**缺口**：好感度数值化、黑话自动沉淀、人格演化持久化、抖音渠道。

## 阶段一（已落地，零代码）

- 打开 `learner.enabled`：开始按群学说话风格
- 角色卡规则：
  - 关系变化用 `[记印象:名字 好感/不爽 原因]` 记下 → 走 people 档案注入
  - 陌生新词用 `[搜索:]` 求证，确认后 `[记事情:词=意思]` 沉淀
  - 不认识梗：看画面 → `[查梗:]` → `[搜索:]`，查不到就承认
- 效果：关系与黑话有「记忆」，但**没有数值**、人格不会变

## 阶段二（需改代码）：好感度系统

新增 `lib/affinity.js`：

```
记录：{ [群号]: { [QQ]: { score, msgs, lastAt, tags[] } } }
更新：被搭话 +1；被夸 +2；被怼 -2；连续 7 天没互动 -1（衰减）
档位：陌生 <3 / 眼熟 3-9 / 熟人 10-24 / 自己人 25+
注入：每轮把「当前说话人」的档位与最近一次原因拼进 context 块
```

接入点：`group.js` 的 `handleGroupMessage`（更新）与 `buildContextBlock`（注入，新增 `relationship` 字段）。
行为：档位写入提示词，让模型对不同人用不同语气（熟人可撒娇、陌生人客气）。

## 阶段三（需改代码）：黑话自动沉淀

- 收集「疑似新词」：短词、重复出现、不在常用词表、上下文含解释性句式（「就是…的意思」）
- 每 N 条让模型归纳一次 → 写入 `slang/<群号>.json`（词、释义、首次出现、例句）
- 命中时注入释义；同一词 3 次未确认则丢弃
- 与 `knowledge.js` 互补：知识库管「群规则/事实」，词典管「词义」

## 阶段四（需改代码）：人格演化

- 每周（或每 200 轮）把档案 + 风格画像 + 关系摘要交给模型，产出「人格增量」：
  - 新增口头禅、偏好、对某些人的态度
- 写回 `personas/<群号>.json`（**不直接改角色卡**，作为 extraPrompt 的叠加层）
- 保留最近 5 代快照，支持 `/qq 人格 回滚 <n>`
- 约束：只允许「语气与偏好」变化，禁止改变身份与底线

## 抖音的实话

抖音没有面向机器人的公开接口，抓取要过签名与风控，稳定性极差且容易被封。建议：
- 不接抖音
- 梗的兜底走「B 站 + 联网搜索」，覆盖已足够
- 如需短视频热点，可加「抖音热搜页」只读抓取（不登录、不评论），作为低权重参考

## 风险与边界

- 协议号本身有封号风险，任何自动学习都会增加发言量，注意频率
- 人格演化必须可回滚，且不允许演化出「违反角色底线」的内容
- 好感度只影响语气，不得用于羞辱或针对性攻击群友
