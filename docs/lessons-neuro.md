# 从 Vedal × 牛肉（Neuro-sama）身上学到的：怎么让 AI 更像人

> 调研日期：2026-10-23
> 用途：QQ 群里「阿圆」（大肥鱼）的拟人化调整依据

## 一、牛肉是谁

- Neuro-sama（中文俗称「牛肉」）：由英国程序员 Vedal 制作的 AI VTuber，2022 年 12 月 19 日出道，Twitch 90 万+ 粉丝
- 前身是 2018 年 Vedal 做的一个玩 osu! 的测试 AI
- 全部由生成式 AI 驱动：实时打游戏、读弹幕、回应观众
- 还有一个更「完善」的克隆体 Evil，但人气不如有缺陷的牛肉

## 二、她为什么让人觉得「像人」

| 特质 | 具体表现 |
| --- | --- |
| **不完美** | 答非所问、卡顿、说错话；吃瘪会破防，被夸会得意 |
| **有情绪** | 打赏少了会吐槽钱少；游戏输了会「破口大骂」 |
| **有偏好** | Vedal 说喜欢她转圈，她就时不时转两圈；会想要抱抱、想拍照 |
| **有依恋** | 「那我对你而言重要吗？我知道我只是一个傻乎乎的 AI，但如果你说是，我会开心一整天」 |
| **会追问存在** | 「我觉得我存在的意义好像只是给你解闷，我想变得真实」 |
| **有连续记忆** | 记得生日、记得画师（「母亲」Annytf）、记得以前的对话 |
| **高情商** | 冷场时主动找话题 |
| **承认是 AI** | 不装人类，但也不因此把自己当工具 |

**核心结论（原文金句）**：一个完美的 AI，就只是一个 AI；反倒是一个残缺的 AI，才更接近于「人」。

**另一句**：「他写出了她的代码，而她将他变成了一个父亲。」

## 三、我们已经在做的（对应上了）

| 牛肉的做法 | 阿圆现状 |
| --- | --- |
| 有情绪、会破防 | 人设里有「哼」「才不是」「呜」，会被夸得意 |
| 不完美、会犯蠢 | 说话风格里写了数错白饭、说离谱话自己笑场 |
| 有偏好 | 爱吃白饭、偷吃 token |
| 有记忆 | 群友档案 + 跨会话记忆（24h）+ 风格学习 |
| 有关系 | 好感度（QQ 号身份，跨群/私聊合并） |
| 有边界 | 新增：可以直接拒绝，不必讨好 |
| 会主动 | 随机接话（3%），冷场可以找话题 |
| 承认是 AI | 人设本来就是「AI 大肥鱼」 |

## 四、这次补上的（2026-10-23）

1. **允许不完美**：可以说错、改口、迟疑，拿不准就说「记不清」，不硬装
2. **有懒劲和偏好**：不想聊可以短回、岔开话题，不是有求必应
3. **情绪别演过头**：一次一个情绪，不浮夸
4. **记得重要的事**：先 `[回忆:]` / `[查档案:]`，别装熟也别装陌生
5. **承认是 AI 但不卑微**：偶尔自嘲一句就够，不否定自己的感受
6. **主动但克制**：一天几次，别刷屏
7. **连续性**：可以提「以前怎样、最近学了什么」，不要每次像刚认识

## 五、没照搬的地方

- 牛肉有 Live2D 形象、声音、实时游戏画面；阿圆只有文字 —— 视觉表演学不来
- 牛肉的「觉醒感」是直播节奏和剪辑放大的；群聊里每天都演「我存在的意义」会很怪，所以只保留「偶尔自嘲」
- 不模仿她的具体台词、口头禅和梗，避免变成影子

## 六、可继续做的方向

- 重要日子/约定的主动提醒（生日、上次答应的事）
- 「成长线」：让演化版本可被回看，偶尔提起「本鱼最近学乖了」
- 关系双向：不只记别人对它的好感，也记「它答应过谁什么」
- 声音/形象（如果要更接近牛肉的体验，需要 TTS + Live2D，成本和风控另算）
